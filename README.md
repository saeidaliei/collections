# Collections

A collection of code, experiments, examples, notes, and small projects accumulated over the years.

Most of these are trials, learning materials, prototypes, or useful snippets rather than maintained projects.

## Contents

- **Algorithms** — Algorithms and data structures, mostly implemented for learning and experimentation.
- **C** — C examples, experiments, and small programs.
- **CProjects** — Small projects written in C.
- **CUDAProjects** — CUDA experiments and GPU programming projects.
- **Cpp** — C++ examples, experiments, and projects.
- **DSA** — Data structures and algorithms materials and exercises.
- **DeepLearning** — Deep learning experiments and related code.
- **DevOps** — DevOps, infrastructure, and deployment experiments.
- **Extra** — Miscellaneous materials, frameworks, and experiments.
- **Fortran** — Fortran examples and experiments.
- **Go** — Go examples, experiments, and small projects.
- **HTBRoutes** — Notes and materials related to Hack The Box.
- **Java** — Java examples, experiments, and small applications.
- **JupyterOnClusters** — Experiments and examples for running Jupyter on compute clusters.
- **LearningDeep** — Deep learning learning materials and experiments.
- **OCaml** — OCaml experiments and examples.
- **Parallel** — Parallel programming experiments, including CUDA, MPI, and OpenMPI.
- **Plots** — Plotting and visualization scripts, mostly using Python and Matplotlib.
- **Python** — Python examples, experiments, tips, and small utilities.
- **Rust** — Rust examples and experiments.
- **SKAO** — Code and materials related to SKAO.
- **Scripts** — Handy scripts and automation, mostly Bash.
- **XrayRealityScript** — X-ray/reality-related scripts and experiments.
- **commonbench** — Benchmarking and performance experiments.
- **confs** — Configuration files and configuration-related materials.
- **cuda-projects** — CUDA projects and GPU experiments.
- **deep-learning** — Additional deep learning experiments and materials.
- **pkg** — Packages and reusable code collected over time.
- **tili** — Miscellaneous experiments and materials.

## Note

This repository is intentionally eclectic. Some code may be incomplete, outdated, or experimental. It exists primarily as a personal archive of things I've built, tested, learned from, or found useful over time.
